## Authentication

- `api_key` — API key sent as header `Parcel-API-Key` — falls back to the `PARCEL_EVENTS_API_KEY` environment variable.
- `bearer_token` — Bearer token — falls back to the `PARCEL_EVENTS_BEARER_TOKEN` environment variable.

```python
client = ParcelEventsSdkFixture260904(api_key="my-api-key")
```

## Pagination

List methods return page objects — iterating one walks EVERY page transparently (`async for` on the async client):

```python
page = client.pickups.list()
for item in page:
    print(item)
# or page-by-page: page.items(), page.has_next_page(), page.get_next_page()
```

## Errors

Non-2xx responses raise typed errors (`APIError` subclasses, body + `x-request-id` attached):

```python
from parcel_events_sdk_fixture_260904 import APIError, AuthenticationError

try:
    ...  # any client call
except AuthenticationError as error:
    print(error.status, error.request_id)
except APIError as error:
    print(error.status, error.body)
```

## Retries & timeouts

Retries are on by default (max 3, exponential backoff from 250 ms, honoring `Retry-After`). Configure per client:

```python
from parcel_events_sdk_fixture_260904 import RetryPolicy

client = ParcelEventsSdkFixture260904(retries=RetryPolicy(max_retries=5), timeout_ms=30_000)
```
